# React-JS-practice

## To Practice:
- Set up React using Vite

- Create a basic React application

- Create reusable components

- Practise JSX

- Create parent/child components

- Apply styling

- Organize the project

## Instructions To Run:
1. Set up React using Vite with:

        npm create vite@latest . -- --template react

2. Run dev server:

        npm run dev

3. View application in localhost url
